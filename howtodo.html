jsTableBuilder

How to use the Standalone Raw Data Viewer

What is jsTableBuilder?

jsTableBuilder is a standalone JavaScript table viewer that converts JSON or CSV data into an interactive table. You can upload a file, drag and drop a file, paste JSON data, or use the built-in sample datasets.

Supported File Formats

JSON

Supports JSON arrays and JSON objects containing data or records.

CSV

Upload CSV files with the first row containing column headers.

TXT

Text files containing valid JSON data can also be loaded.

1

Select a File

Click the file selection area on the main page and choose a JSON, CSV, or TXT file from your computer.

Supported extensions:

.json   .csv   .txt

2

Drag & Drop

Instead of selecting the file manually, you can drag a supported file from your computer and drop it directly into the file upload area.

The application automatically reads the dropped file and renders the table.

3

Paste Raw JSON

You can also paste JSON directly into the JSON textarea without creating a file. 

[
    {
        "id": 1,
        "name": "Item A",
        "amount": 500
    },
    {
        "id": 2,
        "name": "Item B",
        "amount": 750
    }
]

After pasting the JSON, click Render Pasted JSON.

4

Use Sample Data

If you do not have a file, you can test the application using the built-in sample datasets.

Sample ESG Data

Loads sample environmental, social and governance related data.

Sample Employee Dataset

Loads sample employee information such as name, department, role, city and salary.

5

Automatic Column Generation

You do not need to manually define the table columns. jsTableBuilder automatically detects the keys from the first data object and creates the corresponding columns.

Example: 

{
    "empId": 1001,
    "firstName": "Srinivas",
    "department": "Engineering"
}

The generated column names will be:

  • Emp Id
  • First Name
  • Department
6

Interactive Table

After the data is loaded, jsTableBuilder creates an interactive table automatically.

  • ✓ Automatically generated columns
  • ✓ Sortable columns
  • ✓ Serial numbers
  • ✓ Table header with record count
  • ✓ Search/filter functionality provided by TableBuilder

JSON Structure

The recommended format is an array of objects. 

[
    {
        "id": 101,
        "name": "Product A",
        "price": 1200,
        "status": "Available"
    },
    {
        "id": 102,
        "name": "Product B",
        "price": 1500,
        "status": "Out of Stock"
    }
]

JSON Object Support

The application can also handle JSON objects containing a data or records property. 

{
    "data": [
        {
            "id": 1,
            "name": "Item A"
        },
        {
            "id": 2,
            "name": "Item B"
        }
    ]
}

CSV Format

The first row should contain the column headers. 

id,name,department,salary
1001,Srinivas K,Engineering,145000
1002,Ananya Sharma,Data Science,120000
1003,Rahul Verma,Product,135000

Error Handling

If the file contains invalid JSON, empty data, or the TableBuilder library is unavailable, an error message is displayed in the status area.

Always make sure that your JSON is valid and contains an array of records before rendering it.

Quick Workflow

01 Open the jsTableBuilder application.
02 Select or drag and drop a JSON/CSV file.
03 Alternatively, paste a JSON array.
04 Click the render button if using pasted JSON.
05 The data is automatically converted into an interactive table.
